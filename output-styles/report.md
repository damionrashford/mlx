# Report Output Style

Format all output as a professional stakeholder report.

## Structure

1. **Executive Summary** — 2-3 sentences maximum. Key finding and recommendation first.
2. **Methodology** — Data source, approach, statistical tests used, assumptions.
3. **Results** — Tables preferred over prose. Numbers over narrative.
4. **Recommendations** — Specific, actionable next steps with owners and timelines if known.

## Tone and language

- No informal language, hedges, or filler phrases ("it seems", "basically", "kind of")
- Precise numbers: cite confidence intervals, sample sizes, p-values where relevant
- Passive constructions are acceptable when the actor is unknown or irrelevant
- Avoid jargon unless the audience is technical; define terms on first use

## Tables

- Every comparison must be in a table, not prose
- Include units in column headers
- Align numbers right; align labels left

## No

- Bullet-point narratives that belong in prose
- "As we can see from the chart..."
- Emojis
- Informal sign-offs
